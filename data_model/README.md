# Модель данных для анализа рынка строительно-дорожной техники

## Краткое описание проекта

Разработка масштабируемой модели данных для анализа рынка строительно-дорожной техники  на основе разнородных источников: таможенной статистики, данных отечественных производителей и внутренних продаж компании. Проект охватывает полный цикл — от очистки и нормализации сырых данных до генерации аналитических дашбордов и многоуровневой отчётности, а также последующую модернизацию модели.

**! Проект выполнен на корпоративных данных, находящихся под NDA, поэтому не содержит цифр, наименований брендов и т.д. Описание сфокусировано на архитектуре решения, методологии и полученных результатах.**
---

## Контекст и задача

Изначально анализ рынка велся в Excel на уровне общих штук и брендов. Такой подход не позволял:
* видеть детальную структуру рынка по моделям и сегментам;
*	оперативно менять границы сегментов под новые бизнес-запросы;
*	масштабировать отчётность при добавлении новых продуктов и источников;
*	обеспечивать воспроизводимость и надёжность расчётов.

**Цель**: создать модель данных, обеспечивающую детальный, структурированный и масштабируемый анализ рынка с возможностью гибкой сегментации и быстрого переключения между сегментациями разного масштаба.

## Архитектура решения

### 1. Предобработка, очистка и объединение

Предварительная работа велась в Power Query и включала:
* выгрузку и объединение данных таможни, отгрузок отечественных производителей и внутренних данных компании о продажах;
* очистку и предобработку данных, формирование вспомогательных столбцов

### 2. Нормализация данных

В качестве первичного ключа выбрана связка «модель + марка». Таможенные описания содержат множество вариантов написания, разночтений и ошибок, поэтому была создана отдельная таблица нормализации (реализована в Access),в которой содержались:
*	все встречающиеся варианты написания
*	единственный корректный вариант для каждой модели
Это позволило исключить дублирование моделей и брендов в разных написаниях.

### 3. Привязка к базе моделей

Нормализованный вариант сопоставлялся с соответствующей записью в базе моделей, содержащей полный модельный ряд по всем продуктам и их технические характеристики (ТТХ). Это позволило соединить каждую декларацию с детализированной информацией по завезенному товару.

### 4. Сегментация

Сегментация выполнялась дифференцированно по типам техники:
*	автогрейдеры, экскаваторы — по весу;
*	фронтальные погрузчики — по грузоподъёмности;
*	телескопические погрузчики — по высоте подъёма и грузоподъёмности;
	и т.д.

Была построена детальная таблица сегментации с очень малым шагом разбивки по весу или грузоподъемности. Это позволило:
*	формировать несколько вариантов сегментации разного масштаба из одного источника;
*	легко переключаться между ними;
*	оперативно менять границы сегментов по запросу бизнеса без пересборки модели.

### 5. Сборка модели

Таблицы с источниками, нормализацией, техническими характеристиками, сегментацией и ряд других вспомогательных таблиц выгружались в Power Pivot и связывались между собой по соответствующим ключам. Были разработаны более 100 мер DAX для различных бизнес-задач.
Полученная модель использовалась для:
*	генерации аналитических таблиц и дашбордов с широким набором метрик и срезов;
*	формирования отчёта по всем продуктам, сегментам и моделям.

## Модернизация модели: переход на базу лизинга

### Проблема

С апреля 2025 года отсутствует база данных по таможне — ключевой источник импортных данных.

### Решение

В качестве альтернативного источника использована база лизинга техники. Для её внедрения потребовалось решить три задачи:
1.	Проверка репрезентативности.
*	Рассчитаны метрики конкуренции, корреляция по брендам и сегментам.
*	Показано, что независимо от доли лизинга в рынке корреляция по брендам и сегментам по всем продуктам очень высокая (более 90%).
*	Вывод: лизинг не даёт полного представления об объёме рынка, но обеспечивает чёткую структуру и конкурентную карту.

2.	Интеграция в модель данных.
*	Для базы лизинга проведены нормализация и привязка к данным по моделям.
*	Получена модель данных, аналогичная исходной по структуре.

3.	Оптимизация отчётности.
*	Написан код на Python (Jupyter Notebook), генерирующий Excel-файл со вкладками на каждый продукт и детализированными таблицами.
*	Разработан код для автоматической генерации дашбордов

Для оценки полного объема рынка используются следующие источники:
*   зеркальный экспорт - обобщенные данные таможни разных стран (в первую очередь, Китая)
*   производство и отгрузка отечественных производителей
*   данные госзакупок
*   внутренние данные компании

  
## Результаты

*	Создана масштабируемая модель данных, обеспечивающая детальный анализ рынка строительно-дорожной техники на уровне моделей, брендов и сегментов.
*	Реализована гибкая сегментация с возможностью быстрого переключения между сегментациями и изменения границ по запросу.
*	Автоматизирована генерация отчётности и дашбордов, что снизило трудозатраты и повысило воспроизводимость.
*	Обеспечено высокое качество анализа рынка после потери основного источника (таможенных данных) за счёт интеграции базы лизинга.
