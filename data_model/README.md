# Модель данных для анализа рынка строительно-дорожной техники

## Краткое описание проекта

Разработка масштабируемой модели данных для анализа рынка строительно-дорожной техники  на основе разнородных источников: таможенной статистики, данных отечественных производителей и внутренних продаж компании. Проект охватывает полный цикл — от нормализации «сырых» данных до генерации аналитических дашбордов и многоуровневой отчётности, а также последующую модернизацию модели.

**! Проект выполнен на корпоративных данных, находящихся под NDA, поэтому не содержит цифр, наименований брендов и т.д. Описание сфокусировано на архитектуре решения, методологии и полученных результатах.**
---

## Контекст и задача

Изначально анализ рынка велся в Excel на уровне общих штук и брендов. Такой подход не позволял:
* видеть детальную структуру рынка по моделям и сегментам;
*	оперативно менять границы сегментов под новые бизнес-запросы;
*	масштабировать отчётность при добавлении новых продуктов и источников;
*	обеспечивать воспроизводимость и надёжность расчётов.

**Цель**: создать модель данных, обеспечивающую детальный, структурированный и масштабируемый анализ рынка с возможностью гибкой сегментации и быстрого переключения между сегментациями разного масштаба.

## Архитектура решения

### 1. Нормализация данных

В качестве первичного ключа выбрана связка «модель + марка». Таможенные описания содержат множество вариантов написания, разночтений и ошибок, поэтому была создана отдельная справочная таблица (реализована в Access), которая:
*	аккумулировала все встречающиеся варианты написания;
*	приводила каждый вариант к нормализованному виду.
Таким образом, помимо исходного датасета появился слой нормализации, отделяющий «грязные» исходные данные от аналитической модели.

### 2. Привязка к базе моделей

Нормализованный вариант сопоставлялся с соответствующей записью в базе моделей, содержащей полный перечень продуктов и их технические характеристики (ТТХ). Это обеспечило единую точку правды по каждой модели.

### 3. Сегментация

Сегментация выполнялась дифференцированно по типам техники:
*	автогрейдеры, экскаваторы — по весу;
*	фронтальные погрузчики — по грузоподъёмности;
*	телескопические погрузчики — по высоте подъёма и грузоподъёмности;
	и т.д.

Была построена детальная таблица сегментации с очень малым шагом разбивки (порядка 50 кг для весовых категорий). Это позволило:
*	формировать несколько сегментаций разного масштаба из одного источника;
*	легко переключаться между ними;
*	оперативно менять границы сегментов по запросу бизнеса без пересборки модели.

### 4. Сборка модели

Все таблицы связывались в Power Pivot, предобработка выполнялась в Power Query. Полученная модель использовалась для:
*	генерации аналитических таблиц и дашбордов с широким набором метрик;
*	формирования многолетнего отчёта по всем продуктам, сегментам и моделям.

## Модернизация модели: переход на базу лизинга

### Проблема

С апреля 2025 года отсутствует база данных по таможне — ключевой источник импортных данных.

### Решение

В качестве альтернативного источника использована база лизинга техники. Для её внедрения потребовалось решить три задачи:
1.	Проверка репрезентативности.
*	Рассчитаны метрики конкуренции, проведена корреляция по брендам и сегментам.
*	Показано, что независимо от доли лизинга в рынке корреляция по брендам и сегментам по всем продуктам очень высокая (более 90%).
*	Вывод: лизинг не даёт полного представления об объёме рынка, но обеспечивает чёткую структуру и конкурентную карту.

2.	Интеграция в модель данных.
*	В базе лизинга проведены нормализация и привязка к данным по моделям.
*	Получена модель данных, аналогичная исходной по структуре.

3.	Оптимизация отчётности.
*	Написан код на Python (Jupyter Notebook), генерирующий Excel-файл со вкладками на каждый продукт и детализированными таблицами.
*	Разработан код для автоматической генерации дашбордов

## Результаты

*	Создана масштабируемая модель данных, обеспечивающая детальный анализ рынка строительно-дорожной техники на уровне моделей, брендов и сегментов.
*	Реализована гибкая сегментация с возможностью быстрого переключения между сегментациями и изменения границ по запросу.
*	Автоматизирована генерация отчётности и дашбордов, что снизило трудозатраты и повысило воспроизводимость.
*	Обеспечена непрерывность анализа после потери таможенного источника за счёт валидированной интеграции базы лизинга.
