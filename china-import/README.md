# Импорт строительно-дорожной техники из Китая в РФ (2015–2026)

**ETL-пайплайн + интерактивный дашборд в Metabase на публичных данных таможенной статистики Китая.**

Проект полного цикла: от загрузки и очистки CSV-выгрузок таможни до хранения в базе данных и построения дашбордов. Демонстрирует воспроизводимый ETL-процесс и аналитические выводы о динамике, структуре, сезонности и ценах импорта СДТ.

**Данные публичные, проект полностью воспроизводим.**

---

## 🎯 Цель проекта

Проанализировать динамику импорта строительной техники из Китая в Россию:

* объёмы по годам и переломные периоды;
* структуру импорта по видам техники и её смещение;
* темпы роста по продуктам (CAGR в трёх окнах);
* сезонность и аномалии;
* динамику средних цен.

---

## 📊 Данные

**Источник**: таможенная статистика Китая (CSV-выгрузки по товарным кодам ТН ВЭД)
**Ссылка**: [stats.customs.gov.cn](https://stats.customs.gov.cn/indexEn)
**Период**: 2015–2026 гг. (данные завершаются июнем 2026)
**Объём**: ~6 700 записей

**Категории техники** (маппинг кодов ТН ВЭД → справочник):

* бульдозеры
* грейдеры
* фронтальные погрузчики
* колёсные экскаваторы
* гусеничные экскаваторы
* экскаваторы-погрузчики

---

## 🔑 Ключевые результаты

Коротко — что показал анализ (детали ниже):

* **Три периода динамики**: рост до 2020 → ускорение 2021–2023 → спад после 2023.
* **Смена структуры**: фронтальные погрузчики 81% → 39%, гусеничные экскаваторы 2% → 39%.
* **Разная скорость роста**: колёсные экскаваторы выросли в 172 раза, бульдозеры — в 3,4 раза.
* **Сезонность**: аномалия 2024, пик декабря 2025 (гипотеза — утильсбор с 2026).
