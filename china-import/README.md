# Анализ импорта строительно-дорожной техники из Китая в РФ

Аналитический проект: подготовка данных таможенной статистики, 
загрузка в базу данных и построение интерактивного дашборда в Metabase.

## 🎯 Цель проекта

Проанализировать динамику импорта строительной техники из Китая в Россию: 
объёмы по годам, структуру по видам техники, темпы роста (CAGR).

## 📊 Данные

Источник: таможенная статистика (CSV-выгрузки по товарным кодам ТН ВЭД)  
Ссылка: https://stats.customs.gov.cn/indexEn  
Период: 2015–2026 гг.  
Объём: ~6 700 записей.  

Категории техники:
- бульдозеры
- грейдеры
- фронтальные погрузчики
- колёсные экскаваторы
- гусеничные экскаваторы
- экскаваторы-погрузчики

## 🛠 Стек

- **Python** (pandas) — очистка, преобразование, подготовка данных
- **MySQL** — хранение подготовленных данных
- **Metabase** (Docker) — визуализация, дашборды, SQL-запросы
- **Jupyter Notebook** — среда разработки

## 🔄 Пайплайн

1. Загрузка всех CSV-файлов из `data/raw/` в один датафрейм.
2. Сопоставление кодов ТН ВЭД со справочником видов техники.
3. Обработка даты, создание колонок `year`, `month`, `quarter`.
4. Очистка данных: отбрасывание нецелевых категорий, 
   нормализация имён колонок.
5. Экспорт финального датафрейма в `data/analytics.sqlite`.
6. Подключение Metabase к SQLite и построение дашборда.
