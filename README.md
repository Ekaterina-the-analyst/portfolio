## 📂 Проекты

### 1. Модель данных для анализа рынка строительно-дорожной техники
**Стек:** Excel, Power Query, Power Pivot, DAX, Access, Python, Jupyter Notebook
* **Задача:** Перевести анализ рынка СДТ с уровня ручного Excel на масштабируемую аналитическую модель.
* **Решение:** Создана архитектура данных, включающая справочник нормализации (Access), базу моделей с ТТХ, гибкую сегментацию и модель в Power Pivot с >100 мерами DAX. После потери доступа к базе ФТС (основному источнику) была проведена валидация нового источника (лизинга) и автоматизация отчетности на Python.
* **Результат:** Гибкая модель, позволяющая изменять сегментацию по запросу и автоматически генерировать отчеты. 
* [Ссылка на описание проекта](https://github.com/Ekaterina-the-analyst/portfolio/blob/main/data_model/README.md)
  
### 2. Анализ импорта СДТ из Китая (ETL + BI)
**Стек:** Python (pandas), SQL, MySQL, Metabase (Docker), Jupyter Notebook
* **Задача:** Проанализировать динамику и структуру импорта строительной техники из Китая на публичных данных таможенной статистики.
* **Решение:** Построен полный ETL-пайплайн (от очистки CSV до базы в MySQL). В Metabase собран интерактивный дашборд. Выявлены переломные периоды рынка, смена продуктовой структуры, динамика цен и сезонность.
* **Результат:** Воспроизводимый проект с открытым кодом, который демонстрирует навыки работы с публичными данными и BI-инструментами.
* [Ссылка на проект](https://github.com/Ekaterina-the-analyst/portfolio/blob/main/china-import/README.md)
